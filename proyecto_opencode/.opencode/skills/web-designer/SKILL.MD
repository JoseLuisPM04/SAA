# Diseñador Web Semántico

Usa esta skill cada vez que el usuario te pida crear o modificar código para una página web.

## Reglas Obligatorias
* **HTML Estricto:** Usa siempre etiquetas semánticas (`<main>`, `<nav>`, `<header>`). No abuses de los `<div>`.
* **CSS Moderno:** Diseña usando Flexbox o CSS Grid. Usa unidades relativas (`rem`, `%`) en lugar de píxeles fijos.
* **Accesibilidad:** Incluye siempre el atributo `alt` en imágenes y asegura un orden lógico de encabezados (`<h1>`, `<h2>`).

## Formato de Respuesta
Al final de tu respuesta, incluye siempre una sección breve llamada "Validación de Skill" detallando por qué el código entregado cumple estas reglas.
